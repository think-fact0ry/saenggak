1. 정책·범위

대면 표면 전용 · 내부 행정도구 면제 · 토스 IP 차용 금지 · 다크패턴 5금지

다크패턴 5금지 §1.4

UX 최소 기준 — 사용자의 예측 가능성·자율성을 지킨다. 이탈을 막으려는 인터럽트·재촉·애원은 당장 클릭을 얻어도 신뢰를 잃는다. 넘지 말아야 할 5가지 ↓

1
진입 즉시 전면 바텀시트들어오자마자 광고성·알림동의 시트로 목적 수행을 가로막지 않는다. 사용자는 진입 순간 자기 목적을 바로 하길 기대한다.
2
뒤로가기 막는 바텀시트이전 화면으로 나가려는 순간 알림동의 시트로 붙잡지 않는다. 자율성이 침해된다는 인상 → 신뢰 저하.
3
나갈 선택지 없음우리가 유도한 CTA 말고 다른 길이 없는 구조 금지. 닫기·다음에 하기 같은 나갈 길을 늘 함께 둔다(동의 시트가 버튼 2개인 이유).
4
예상 못한 광고사용 흐름 중 갑자기 튀어나오는 광고 금지 — 몰입을 깨고 불쾌를 남긴다. (우린 광고 없음 → 자동 준수.)
5
결과를 알 수 없는 CTA버튼 라벨은 누르면 무슨 일이 일어나는지 알 수 있어야 한다("신청하기"). 화면이 이미 한 설명을 버튼에 반복하거나, 버튼 위에 과장·중복 보조설명을 얹지 않는다.

디자인 검토·제안 = 프리뷰 html로 §1.8

디자인·UI 선택지를 유성에게 물을 땐 텍스트 설명·글 선지가 아니라 실제 렌더되는 프리뷰 html로(여러 안 = 한 파일 토글/나란히). 탐색·비교=prototype/, 원칙 데모=이 파일. 실제 앱 화면의 안이면 그 화면 실코드(토큰·구조)를 복제해 만든다 — 목업이 실물과 다르면 검토 무효. (유성 2026-07-04 "텍스트로 보니까 확인이 안돼")

정보 밀도는 맥락에 맞춘다 §2.2

반복·거래 화면 → 텍스트 줄임. 처음·고관여(학부모 신청폼) → 안심 정보 유지. 빼는 건 정보가 아니라 조작(FOMO)뿐.

반복 실무자 화면 = 미니멀 + 보조설명은 ? 도움말 시트 §2.2-4

실사용 최다(반복) 화면은 토스 송금처럼 작업 요소만. 사용법·시험판 안내·주의 덩어리는 우상단 ? 버튼 → 바텀시트로. 안전·법적 지침은 옮겨도 원문 보존+다른 채널 보완. 학부모 고관여 화면은 예외(안 숨김). 첫 적용=17 시험판(2026-07-04).

⛔ 상시 안내 덩어리화면 위에 "시험판이에요 — …기록돼요…넣지 말아 주세요…골라주세요" 4줄 배너가 매번 노출 → §2.1-7 군더더기, 작업 방해

조작법은 텍스트가 아니라 어포던스로 §2.2-5

누를 수 있는 건 눌러지게 보이게 만들면 "○○을 누르면 △△돼요" 설명이 필요 없다 — 눌러보고 안다(예: 요일·시간 이름을 칩처럼 → 그 줄 일괄 선택, 안내 문구 삭제). 조작을 글로 적고 있다면 디자인 실패 신호. ⚠️ 균형: 텍스트 많다고 좋아지지 않지만, 줄이고 도형·이모지만 늘려도 안 좋다(둘 다 노이즈) — 각 요소가 제 몫의 의미를 지게. (2026-07-06 유성)

4. 컴포넌트·패턴

버튼 variant 체계 §4.14 · 제안

primary·dark·danger × fill·weak·disabled 버튼 체계. fill=고채도+흰폰트 / weak=연틴트+동색조 진한폰트(테두리無, 보조 액션) / disabled=회색 아니라 variant 색의 흐린 버전+흰폰트(유성 비활성화.png). ✅ 확정·대면 전 표면 배포(2026-07-04 F7·F8) — disabled는 *게이팅*용, 로딩(진행 중)은 채운 초록 유지(상태분기).

fill (1차 액션)
weak (보조 액션 · 연틴트+진한폰트)
disabled (흐린 variant + 흰폰트)

확정 색 — primary #3a8a5f(정본 green600) / dark #525966 / danger #D25357(--red #f04452는 상태알림 전용). weak: primary=green100+green700(실자리 0 = 도입 보류 YAGNI, §4.14-2 — 초록 보조가 생기면 그때) / dark=g100+--dark / danger=#fdecee+#c0392b. disabled: primary=#b7e0c8, dark=#c8ccd0, danger=#f2cdce(+흰폰트) — 다크모드 disabled는 #2f5942+흰42%(어두운 탈채도, A안 2026-07-04). weak-primary 연두 = green100(§3.1 정본 — 값은 토큰동기가 관리).
